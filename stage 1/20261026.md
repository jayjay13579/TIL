## CLI, 터미널, Shell, Git Bash 개념

- CLI(Command line interface) : 텍스트로만 컴퓨터를 조작하는 방식
  - <-> GUI(Graphical user interface)
  - 장점  
     - 프로그램 설치, 삭제, 수정, 탐색 등을 클릭 대신 명령어 한줄로  
     - 반복 작업, 자동화가 쉬움
     - 자유도 높음, 명령어를 조합하여 다양한 작업이 가능

- 터미널 : CLI라는 규칙을 가지고 동작하는 프로그램, 명령을 입력하고 결과를 보는 창
  - 클로드 코드 등은 CLI 규칙을 가졌지만 터미널로 실행을 하는 도구임

- Shell : 터미널 안에서 명령을 해석해 실행하는 프로그램
  - shell의 종류에는 windows Powershell, 명령프롬프트의 cmd, mac OS/Linux의 Bash 등이 있고
    각각 명령어와 스크립트 문법이 조금씩 다름
  - ex) Bash 셸 : 명령을 읽고 실행하는 프로그램 / Bash 언어 : 프로그램에 명령할 때 쓰는 문법
  - Bash : 가장 널리 알려지고 오래 사용된 셸 중 하나. 특히 Linux에서 많이 쓰였고,
    macOS에서도 오랫동안 기본 셸이어서 개발자들에게 아주 익숙한 대표적인 셸임

- Git Bash : windows용 Git(버전관리도구) + Bash(셸), 일종의 터미널(사용환경), 커맨드 툴

## Git과 Github

- Git : 버전 관리 시스템(VSC, version control system), 형상 관리 도구
  - 파일의 변경 이력을 기록, 원하는 시점으로 되돌릴 수 있음
  - 분산형(DVCS). 중앙 집중형 버전 관리 시스템과 달리 모든 개발자가 각각 로컬 저장소를 가짐  
    중앙 서버에 문제가 있어도 소스코드 유실 X, 서버 연결 없이 커밋, 이력조회, 브랜치 작업 가능
  - 명령어가 140개 정도 있고 옵션에 따라 다양한 조합이 가능해짐 -> 초기 학습 난이도 높음

- Github : Git 원격 저장소를 호스팅하는 웹 서비스(2018년 MS 인수)
  - 세계 최대의 오픈소스 저장소  
  - pull request(PR), issues(발생 이슈 트랙킹), actions 등 협업기능 제공
  - 유사 서비스 : 깃 랩, 빗버킷 등
  - 최근에는 개발자들이 포트폴리오로도 많이 활용

> 깃은 내 컴퓨터에서 동작하는 도구, 깃 허브는 깃 저장소이자 소스코드를 올려두고 함께 쓰는 서비스  
> 참고로 깃 허브 없이도 깃은 쓸 수 있다.

## 터미널 명령어(1)

### 폴더, 파일 리스트 뽑기 : ls
- ls : 홈 디렉토리 내 여러 폴더, 파일 리스트 확인 가능
- ls - al : (a: 전체 데이터, 숨겨진 것도 볼 수 있음 / l: 자세히 볼 수 있음) 홈 디렉토리 내 모든 폴더, 파일 확인 (날짜 앞에 적힌 숫자는 파일 사이즈)

> drwxr 등 앞에 적혀있는건 파일, 폴더의 접근 권한 의미 / d는 디렉토리, 폴더 / l 은 링크파일(바로가기) *os는 이를 파일로 취급 / -로 시작 : 일반 파일 / rwx 세번 반복 : 소유자, 그룹, 제3자 접근권한 의미(각각 read, write, exectuion 의미)


- ls -alh : 파일 사이즈를 우리가 알기 쉬운 사이즈로 적어줌(단위 없으면 byte, h는 휴먼 리더블 뜻)

### 디렉터리 변경 : cd

> . 현재 디렉토리 /
> .. 상위 디렉토리 의미
> 틸트 ~ 기호는 홈 디렉토리 의미

- cd 디렉터리명 : change directory 
-> 적고나면 ~/kant 등 입력한 디렉터리가 뜨며 해당 폴더에 들어가짐

- cd .. : 상위폴더 이동

- cd ~ : 홈 디렉토리로 이동

- pwd : 프린트 워킹 디렉토리

- cd 디렉터리 첫글자 + tab : 디렉터리명 자동완성하여 이동

- cd - : 바로 이전 작업 폴더로 이동

> [주의] 작업하면서 경로 계속 확인하기(pwd 명령어로 현재 경로 확인 가능), 참고로 모든 폴더에 기본적으로 .(현재폴더), ..(상위폴더) 파일 2개 만들어짐

### 파일에 내용 추가하기 등 : echo

- 문장을 터미널에 출력 : echo 문장

   ```$ echo Helloworld``` -> 터미널에 그대로 Helloworld 출력

- 사용중인 Shell 출력 : echo $SHELL (*대문자)

   ```$ echo $SHELL``` -> /usr/bin/bash 등 출력
     > shell : 실제 컴퓨터 os와 내가 실제로 대화할 수 있는 명령어의 종류. shell interface는 다양함(Gshell, git bash 등)

- 내용을 파일로 보내서 출력 : echo > file

   ```$ echo "Hello world" > README.md```

- 파일 마지막에 append 하기 : echo >> file

   ```$ echo "Welcome to KANT" >> README.md```
