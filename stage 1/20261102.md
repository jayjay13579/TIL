## 4️⃣ 문자열 formating

### 1. 기본 방식 : "%s, %d" % (문자열 변수/값, 정수 변수/값)

- s: 문자열,  d: 정수, f: 실수
- "%n내용" % 변수 : 출력 너비 n칸 지정 후 오른쪽 정렬
  - 왼쪽 정렬 시에는 -n으로 작성
- "%.nf" % 실수 : 실수 소수점 n자리까지 표기 
- 단, %f 방식으로는 천 단위 쉼표를 직접 넣을 수 없음

```py
print("기본 출력: %s, %d" % ("손흥민", 20)) # s: 문자열, d: 정수
# 기본 출력 : 손흥민, 20

print("기본 출력: [%5d]" % (20)) # 출력 너비 5칸 지정, 오른쪽 정렬
#[ ]는 빈칸 확인 위해 임의 추가
# 기본 출력 : [   20]

print("기본 출력: [%-5d]" % 20) # 출력 너비 5칸 지정, 왼쪽 정렬
# 기본 출력: [20   ]

print("소수점 표기: %.2f" % 3.141592) # 소수점 2자리까지 표기, f: 실수
# 소수점 표기: 3.14
```
</br>

### 2. .format 방식 : "{0} {1} {2}".format(변수/값1, 2, 3)
- "{}".format() : ()의 변수 인덱스를 {}안에 넣어 표시
  - 변수를 순서대로 넣는 경우 인덱스 생략하고 {}만 작성 가능 
  - {} 개수는 변수보다 적어도 됨(앞부터 순서대로 넣고 남은 변수는 사용x)
  - 단, {} 개수가 변수보다 많으면 IndexError 발생
- "{:,d}".format(숫자) : 천 단위 , 표시
- "{:.nf}".format(숫자) : 소수점 n까지 표시
  - (ex) "{:,.2f}".format(숫자) : 소수점 n까지 천 단위 넣어서 표시 
- "{:</>n}" : 으로 좌, 우 정렬과 칸 너비 지정 가능
  - (ex) "{:>30,.2f}" : 30칸, 오른쪽 정렬, 천단위 표시, 소수점 2자리까지 표시

```py
name = "cake"
price = 6500
qty = 2
format_str = "주문내역 : {0} {1}  -> 총 {2}원".format(name, qty, price*qty)
# 계산식 변수 가능

format_str = "주문내역 : {} {}  -> 총 {}원".format(name, qty, price*qty)
# 인덱스 생략해도 결과 동일

# "{:,.2f} 원".format(13000) -> 13,000.00원으로 출력

print(format_str)
# 주문내역 : cake 2  -> 총 13000원
```
</br>

### 3. f-string 방식 : "f{변수/값}"
- 가장 일반적으로 쓰이는 formating 방식
- {} 안에서 .format 방식과 같이 칸 너비, 정렬방향, 천 단위 구분, 소수점 절삭 등 지정 가능
  - (ex) f"{123456.123456:>30,.2f}" : 칸 너비 30, 우 정렬, 천 단위 구분, 소수점 2자리까지 -> 123,456.12
- {} 안에 문자열을 넣어 정렬하는 경우 ' ' 처리 
  - (ex) f"{'메뉴명':<10}" : '메뉴명' 적을 칸 너비 10, 좌 정렬

```py
name = "cake"
price = 6500
qty = 2

format_str = f"주문내역 : {name} {qty} -> 총 {(price*qty):<10,}원"
#{} 안에 계산식을 넣을 수 있음
print(format_str)

print(f"금액 : {15000:>8,}원") # 우 정렬, 칸 너비 8, 천 단위 구분
# 금액 :   15,000원
```

#### [예제] 영수증 작성
```py
# 가상의 주문 데이터
orders = [ 
    ("Latte", 5000, 2),
    ("Americano", 3000, 1),
    ("Cake", 6000, 1)
]

print("="*36)

# 항목명 작성
print(f"{'메뉴명':<10} {'단가':>8} {'금액':>9}") # 문자열도 {}안에서 정렬 가능, 단, ' ' 처리

# 구분선
print("-"*36)

# 총 금액 계산
total_amount = 0
for menu, price, qty in orders: # orders 리스트 한 행 각 항목을 menu, price, qty로 받아옴
    subtotal = price * qty
    total_amount += subtotal
    print(f"{menu:<14} {price:>8} {subtotal:>10,}")

# 구분선
print("-"*36)

# 합계 금액
print(f"{'합계 금액:':<20} {total_amount:>9,}원")
```

🔽 실행결과
```text
====================================
메뉴명              단가        금액
------------------------------------
Latte              5000     10,000
Americano          3000      3,000
Cake               6000      6,000
------------------------------------
합계 금액:                  19,000원
```

## 1️⃣ 리스트

### 1. 리스트의 가변성
```py
shopping_list = ["apple", "banana", "cherry"]
print(shopping_list) #['apple', 'banana', 'cherry']
print(shopping_list[0]) # apple

shopping_list[0]="kiwi" # 인덱스 0의 값 수정(덮어쓰기)
print(shopping_list[0]) # kiwi
print(shopping_list) #['kiwi', 'banana', 'cherry']
```
### 2. 리스트 메서드 : append, insert, remove 등
- 메서드 : 실행, 추가, 삭제 등을 명령하는 일종의 동사 역할 수행

```py
fruits = ["apple"]

# append(값): 리스트 마지막에 값을 추가
fruits.append("banana") 
print(fruits) # 메서드는 원본을 바꾼다!

# insert(인덱스, 값): 원하는 인덱스 위치에 값을 추가
fruits.insert(0,"kiwi") # insert(인덱스 넘버, 값)
print(fruits) 

# remove(값): 해당 값을 기존 리스트에서 삭제
fruits.remove("apple")
print(fruits) 
# 'grape' 같이 기존에 없는 값을 삭제하려하면 ValueError 발생
```

### 3. 인덱스
- 파이썬은 음수 인덱스 기능을 지원하는 언어 중 하나

```py
colors = ['red', 'green', 'blue']
print(colors[0]) # red

```

### 4. 슬라이싱

```py
numbers = [0,1,2,3,4,5] # numbers[시작:끝:간격]

# 1번부터 4번 미만까지
print(numbers[1:4]) # [1, 2, 3]

# 2칸 간격으로 추출
print(numbers[::2]) # [0, 2, 4]

# 역순으로 추출
print(numbers[::-1]) # [5, 4, 3, 2, 1, 0]

# 인덱스 4번값부터 역순으로 2칸 간격 추출
print(numbers[4::-2]) # [4, 2, 0]

# 앞에서 3개만 추출
print(numbers[:3]) # [0, 1, 2]

# 인덱스 3번값부터 끝까지
print(numbers[3:]) # [3, 4, 5]

# [참고] 튜플도 슬라이싱 가능
print((10,20,30,40)[1:3]) # (20,30)
```

### 6. 리스트의 길이, 포함 요소
- len(리스트)로 리스트의 길이(포함 요소의 개수) 알 수 있음
- 값 (not) in 리스트 : 리스트 내 해당 값의 포함 여부 확인 가능

```py
user_roles = ["admin","member","guest"]

```
