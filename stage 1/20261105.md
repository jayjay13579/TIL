## 2️⃣ 클래스에 정보와 기능 담기

### 1. 클래스 관련 기본 개념

- 클래스에 인스턴스가 가질 **정보**와 그 정보를 다루는 **기능** 정의 가능
    - 속성 : 인스턴스가 가진 정보 ---> __init__ 으로 정의
    - 메서드 : 인스턴스가 사용할 수 있는 기능, 인스턴스 정보/상태 변경 ---> def로 정의  
      *클래스 안에 쓰면 함수가 아니라 메서드! 

- **self** : 메서드가 작업하는 인스턴스 자신, 누가 호출하느냐에 따라 메서드  
  결과가 달라지므로 self 매개변수를 통해 어떤 객체에 대해 호출하는지 보여줌
  - 파이썬에서는 메서드가 어떤 객체를 다룰지 알 수 있도록 해당 객체를 첫 번째 매개변수로 전달
  - 인스턴스가 메서드를 호출할 때 self는 파이썬이 자동으로 전달, 직접 입력X  
    *만약 입력하면 다음 매개변수에 self를 넘겨주는 것으로 인식하여 오류!
  - ⭐ 언제 self.를 붙여서 코드 작성해야 할까? 현재 객체가 가진 정보나 기능에 접근할 때!!  
    (ex: self.shopping_list => 아무나의 쇼핑 목록이 아니라 이 사람의!! 쇼핑목록!)
    => . 앞에 누구 것인지 소유자(self)를 적는다고 생각한다! 

**[예제] 회원 등록 툴 만들기**
```py
# 회원 등록 틀 만들기
class User: 

    # __init__ : 클래스 안에서 쓰는 초기화 메서드, 인스턴스 초기 상태 설정
    def __init__(self, name): # name : 회원 인스턴스가 가진 정보
        self.name = name # 전달받은 name을 이 회원 self.name에 저장
    
    # 회원 이름을 알려주는 기능 : show() 추가
    def show(self):
        return f"회원 이름: {self.name}"

# 회원 이름 정보 저장하기 (📌메커니즘 아래 참고)
user_a = User("손흥민") # 새 User 인스턴스 생성, name 저장
user_b = User("김연아")

# 각 회원의 기능 사용하기(class 내 메서드)
# 파이썬이 자동으로 show(user_a/b) 처리, self 인수 넣지 X
print(user_a.show())  # 회원 이름: 손흥민
print(user_b.show())  # 회원 이름: 김연아
```
> 📌 User() 클래스가 호출될 때 발생하는 일
> 1. 새로운 User 인스턴스 생성
> 2. __init__ 자동 호출 -> 이름 넣는 칸 생기는 것!
> 3. self = 새 인스턴스, name = "손흥민" 으로 할당
> 4. self.name = name이 실행되어 인스턴스에 이름이 저장

### 2. 클래스 안에서 쓰는 특별 메서드(dunder method, 던더 메서드)

| 메서드 | 주로 언제 호출될까? | 역할 |
|---|---|---|
| `__init__` | 인스턴스를 만들 때 | 처음 상태를 설정 |
| `__str__` | `print(객체)`, `str(객체)` | 사람이 읽기 좋은 표현을 제공 |
| `__repr__` | `repr(객체)`, 리스트 안 객체 출력 등 | 개발자가 객체를 확인하기 좋은 표현 제공 |
| `__len__` | `len(객체)` | 객체의 길이를 제공 |

#### **[추가 설명]**
- **__init__ (생성자)** : 인스턴스 만들어진 직후, 처음 정보/상태를 설정하는 특별한 메서드
  - 클래스에 따라 생성자가 없을 수도 있음. 초기값 설정 필요시에만 사용!
  - init 안에 print(), 다른 메서드 등 호출할 수 있음. > 인스턴스 생성시 즉시 실행되도록
  - 주의 : init은 None을 반환하도록 되어있음, 다른 값 return하도록 지정할 수 없음!🚨
    뭔가 반환하고 싶다면, init에 return 값 설정 X, self.name = name처럼 객체에 저장⭐

- **__str__** : 객체를 사람이 읽기 편한 문자열로 출력(print)하는 방법을 정함

- **__repr__** : 객체를 확인(리스트에서 꺼낼 때 등)할 수 있는 문자열 표현을 정함
  - 먼저 __str__이 정의되지 않으면 print()에서 __repr__이 대신 사용됨

### **[예제] 은행계좌 만들기**
```py
class BankAccount:
    # 계좌 기본 정보 정의(예금주, 잔액 정보 받기)
    def __init__(self, owner, balance):
        self.owner = owner # 예금주
        self.balance = balance # 잔액

    def __str__(self): # str? 어떤때 쓰는거? 인스턴스를 사람이 읽기 좋은 문자열로 표현
        return f"예금주 : {self.owner}, 잔액 : {self.balance:,}" # 천 단위 구분 :,

    def __repr__(self): # representation
        return f"예금주 : {self.owner}, 잔액 : {self.balance:,}"

    # 입금 처리 메서드
    def deposit(self, amount):
        self.balance += amount # 입금 처리
        print(f"{amount:,} 입금 완료 / 잔액 : {self.balance:,} 원")

    # 출금 처리 메서드 (내 코드)
    def withdrawl(self, amount):
        # 잔액 확인
        if amount > self.balance: # 잔액이 부족하면
            print(f"잔액이 부족합니다. 현재 잔액 : {self.balance:,} 원")
            
        else:
            self.balance -= amount # 출금 
            print(f"{amount:,} 출금 완료 / 잔액 : {self.balance:,} 원")
            return self.balance # 출금 후 잔액 return 

account_a = BankAccount("이지혜", 100_000) # 인스턴스 생성

print(account_a) # 예금주 : 이지혜, 잔액 : 100,000
account_a.deposit(500_000) # 500,000 입금 완료 / 잔액 : 600,000 원
account_a.withdrawl(500_000) # 500,000 출금 완료 / 잔액 : 100,000 원
account_a.withdrawl(500_000) # 잔액이 부족합니다. 현재 잔액 : 100,000 원
```

#### **⭐ 더 좋은 코드를 위한 사고방식 : 조기 반환! ⭐**
- 교안에서는 출금처리 메서드에서 if, else 대신 if ~ return을 씀
- 잔액이 부족한 경우를 먼저 처리하고 함수에서 빠져나오므로(조기반환 early return 방식)  
  정상적인 출금 코드가 덜 들여쓰기 되어 읽기 편함.. 로직 단순 + 읽기 쉽게!
```py
    # 출금 처리 메서드 교안 ⭐
    def withdraw(self, amount):
        # 잔액 확인 
        if self.balance < amount:
            print(f"잔액 부족")
            return 0 # return None 등으로 빠져나오기, 여기서 메서드 종료

        self.balance -= amount
        print(f"{amount:,} 출금 처리")
        return self.balance # 출금 후 잔액 리턴
```
- 실전 코딩에서 좀 더 로직이 짧은 조건을 먼저 두고 if ~ return 으로 코드짜면 효율적⭐
  - (ex) '미성년자는 출입 불가' (굳이 if 성인, else 미성년자 같은 식으로 늘여쓰지 X)
```py
  def enter(age):
    # 출입할 수 없는 경우를 먼저 처리 -> return으로 함수 바로 종료
    if age < 19:
        print("미성년자는 출입할 수 없습니다.")
        return

    # 위에서 종료되지 않았다면 출입 허용
    print("입장하세요!")
    
enter(17)  # 미성년자는 출입할 수 없습니다.

```
