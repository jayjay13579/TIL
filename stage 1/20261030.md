### 1️⃣ uv 설치하기

---
- uv : 파이썬 개발에 필요한 환경과 도구를 관리해주는 PG, 터미널에서 명령어 입력해 사용  
  (ex) 파이썬으로 csv 파일을 분석하려고 pandas 라이브러리를 쓴다면?  
       uv가 해당 라이브러리 설치, 버전 관리까지 모두 해줌!  
```sh
# 프로젝트 폴더에 pandas 추가
uv add pandas

# 프로젝트 환경에서 app.py 실행
uv run python app.py
```

- uv의 주요 역할
  - 라이브러리 설치 : pandas 처럼 다른 사람이 만든 기능을 가져와 사용
  - **가상환경 관리** : 프로젝트마다 라이브러리를 따로 설치해 서로 영향을 주지 않도록 관리
  - **파이썬 버전 관리** : 프로젝트에 필요한 파이썬 버전을 설치하고 사용
  - 프로그램 실행 : 필요한 환경을 준비해 코드를 실행

> 🚨 개발 환경에서 파이썬 사용할 때 가장 주의할 점 : 버전 맞추기!  
> uv를 통해 가상환경 만들고 그 안에서 설치해서 작업(작업 후 가상환경 삭제)  
> 하는 방식으로 각 버전을 잔뜩 깔아서 작업환경 오염되는 문제 방지 가능!

## 2. uv run : uv로 관리 시작, .venv 가상환경 활성화
- 첫 run에서 uv가 하는 일
  - 파이썬 찾기(없으면 설치)
  - **.venv 생성**
  - uv.lock과 **동기화** : 동기화는 프로젝트의 가상환경 .venv를 uv.lock에 기록된   
  패키지 구성에 맞추는 것 -> 대부분의 경우 따로 uv sync를 하지 않아도 됨
  > uv.lock: 실제로 사용할 패키지와 그 버전을 자세히 기록한 파일
```sh
$ uv run main.py
Creating virtual environment at: .venv # .venv(프로젝트 전용 가상환경) 생성
Hello from practicefile!
```

(+) source .venv/Scripts/activate : 프로젝트 가상환경 켜기
```sh
$ source .venv/Scripts/activate
# source : 뒤에 지정한 파일 내용을 현재 터미널에 적용
# .venv 이하 : 가상환경을 켜는 설정이 들어있는 파일
```

(+) which : 가상환경 내 파이썬 사용 상태 확인
```sh
$ which python # which : 명령어 실행할 파일 위치 보여줌
```
