# 01 README 파일 작성과 기타 참고 사항

## 1. README 작성법
- README 파일 : 코드를 처음 보는 사람이 “이게 뭔지 → 어떻게 실행하는지 → 어떤 기능이 있는지” 순서로 이해할 수 있게 작성

  ```text
    (ex) 장바구니 프로젝트의 README 파일
    1. 프로젝트 소개 — 어떤 프로그램인지 한두 문장
    2. 실행 방법 — 필요한 환경과 실행 명령어
    3. 주요 기능 — 상품 목록, 담기·빼기, 쿠폰, 결제 등
    4. 프로그램 구조 — 주요 함수와 클래스의 역할
    5. 실행 흐름 — 메뉴 선택부터 결제까지
    6. 참고 사항 — 재고 저장 방식이나 현재 제한사항
  ```
## 2. 기타 코딩 참고 사항
- uv init --no-package 다음에 프로젝트명 작성 가능(프로젝트 밖에서 uv 초기화 할 때)

- vscode 프로젝트 내 ctrl + n으로 빈 파일 생성(touch와 동일) -> ctrl + s로 저장하며 이름 지정

- vscode에서 함수, 요소 등 지정 후 f12(혹은 ctrl + 클릭)하여 코드 내부 확인 가능

### 1. Pet 클래스 생성 및 기본 속성, 출력 내용 제어
```py
class Pet: # 다마고치 펫에 대한 클래스

    count = 0 # 지금까지 입양한 펫 수를 기록
    # 클래스 변수 : 클래스의 객체들이 공유하는 변수(<-> 인스턴스 변수 : 객체마다 저장)
    # 클래스 변수는 클래스 안, 메서드 밖에 작성

    # 펫 기본 속성 : 이름, 배고픔/행복도/에너지 초기값, 잔류 상태 지정
    def __init__(self, name):
        self.name = name # 이름
        self.hunger = 30 # 배고픔 (범위는 0~100)
        self.happy = 70 # 행복도
        self.energy = 70 # 에너지
        self.alive = True # 잔류 상태

        # 펫 추가시 클래스 변수 카운트
        Pet.count += 1 # 인스턴스 하나 생성될 때마다 펫 수 증가

    # 펫 인스턴스 기본 출력 내용 : 
    def __str__(self): # 인스턴스 출력시 
        state = self.mood() if self.alive == True else "떠남" # 한줄 코드 연습 ⭐
        return (f"{self.name} {state}\n" # mood는 메서드이므로() 써줘야 함!
                f"배고픔: {self.bar(self.hunger)} {self.hunger:>3}\n"
                f"행복도: {self.bar(self.happy)} {self.happy:>3}\n"
                f"에너지: {self.bar(self.energy)} {self.energy:>3}\n")

    # pet 기분을 알려주기 위한 mood 메서드 : 이모티콘 출력
    def mood(self): # 배고픔, 행복도 2개 수치를 가지고 판단
        if self.hunger >=80 or self.happy <= 20: return "😭" 
        if self.happy >=70 or self.hunger <= 40: return "😄"
        return "😐"

    # 기본 상태 출력을 위한 bar 메서드 : 게이지 시각화
    def bar(self,value): 
        filled = value // 10 # 0~100 사이의 상태값을 10칸의 막대로 변환
        return "🟩" * filled + "⬛" *(10-filled) # 상태값 칸수는 초록, 10개 중 나머지 칸수는 검정으로 표현
```
### 2. 상태값 변경을 위한 공통 내부 메서드 작성 ⭐⭐⭐

- 비공개 메서드(private method)/내부용 메서드(internal method) : 객체를 사용하는 쪽에서  
  단독으로 직접 호출하기 보다는, 클래스의 다른 메서드가 내부적으로 사용할 수 있도록 만든 메서드
  - 보통 메서드 이름에 _ (언더스코어) 하나를 붙여서 관례적으로 사용함
  - '외부 클래스에서는 호출하지 마세요' 라고 하는 의미
  
- 예제에서는 3번의 기능 메서드들이 잘 작동하는 것을 돕기 위해 _clamp, _change 내부 메서드를 만듦

```py
    # 공통 내부 메서드 _change(범위에 맞는 적정 상태값 반환)
    # _change 내부 메서드를 위한 내부 메서드...내부 내부 메서드(?)
    def _clamp(self, value):
        # 값의 범위를 (0~100 사이로 유지)
        if (value <0): return 0
        if (value >100) : return 100
        return value # 적정한 값을 반환

    # 공통 내부 메서드 _clamp(상태값 받아오고 변경)
    # 아래의 feed, play, sleep, pass_time 메서드를 위한 내부 메서드
    def _change(self, hunger = 0 , happy = 0, energy = 0): # default 값
        self.hunger = self._clamp(self.hunger + hunger) # _clamp 메서드로 적정값 반환받은 후 변경
        self.happy = self._clamp(self.happy + happy) 
        self.energy = self._clamp(self.energy + energy) # 상태값은 항상 이 clamp 메서드를 거쳐서 변경
```

### 3. 게임 플레이를 위한 필수 기능(밥주기, 놀아주기, 잠자기) 메서드 작성
```py
    # [기능 1] 밥주기
    def feed(self):
        # 제약 조건
        if self.hunger <= 10 : # 배고픔 값이 10 이하라면
            print(f"{self.name}: 배불러요~")
            return False # 밥주기 실행하지 않음
        self._change(hunger = -30, happy = 5) # 그 외 경우는 밥주기(배고픔 -30, 행복 +5)
        print(f"{self.name}에게 밥을 줬습니다. 냠냠")
        return True # 실행은 True로 반환

    # [기능 2] 놀아주기
    def play(self):
        # 제약 조건
        if self.energy < 20: # 에너지가 20 미만이라면
            print(f"{self.name} : 너무 피곤해요...")
            return False # 놀아주기 실행하지 않음
        self._change(hunger=10, happy=25, energy=-20) # 그 외 경우는 놀아주기(배고픔 +10, 행복 +25, 에너지 -20)
        print(f"{self.name}와 신나게 놀았습니다!")
        return True # 실행은 True로 반환

    # [기능 3] 잠자기
    def sleep(self):
        # 제약 조건
        if self.energy >= 80: # 에너지가 80 이상이라면
            print(f"{self.name} : 더 놀고 싶어요!")
            return False # 잠자기 실행하지 않음
        self._change(hunger=5, energy=40) # 그 외 경우는 잠자기(배고픔 +5, 에너지 +40)
        print(f"{self.name}가 잠들었어요. zZ")
        return True # 실행은 True로 반환
```

### 4. 추가 기능(시간 경과 및 확률 이벤트) 메서드 작성 ⭐⭐⭐
- 특정 확률에 따라 코드가 실행되도록 하려면? random.randint 활용!!!
  - (ex) if (random.randint(1, 5)==1): # 1~5 중에 1이 나올 확률 = 1/5 = 20% 
```py
    # 시간 경과 체크 메서드
    def pass_time(self):
        # 하루 지날때 마다 상태값 자연 감소
        self._change(hunger=10, happy=-10, energy=-5)
        # 20% 확률 이벤트 발생

        if (random.randint(1, 5)==1): # 1/5 확률이면 = 20%면
            self._change(happy=15)
            print(f"{self.name} : 숨겨진 장난감을 찾았어요.")

        if self.hunger >= 100 or self.happy <=0: # 만약 배고픔이 높고 행복도 낮으면
            self.alive = False # 잔류하지 않고 떠난 상태
```

### 5. 실행 코드
```py
choco = Pet("초코")

    day += 1
```
