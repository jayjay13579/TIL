# 미니 프로젝트 1 : 가위바위보 게임

```text
[개인별 미니 프로젝트1 - 가위바위보 게임]
- 컴퓨터가 난수를 발생시켜 가위 / 바위 / 보 데이터 저장
- 플레이어 화면에 가위 / 바위 / 보 번호를 입력
- 승패 판정 결과
- 화면 예시
========================================
        가위 / 바위 / 보 게임
========================================
1. 가위 / 2. 바위 / 3. 보
번호를 선택하세요. :

[게임 결과]
나: 보  vs  컴퓨터: 바위
=> 승리 / 패배 / 비김

현재 스코어  나 1 : 0 컴퓨터

다시 도전 (yes/no) : yes

+ [도전 기능]
- 플레이어 이름 입력 받아서 승패 기록에 표시
- 3판 2선 승제로 최종 결과 계산
- 각 판별 승패 목록 표시
- 연승 기록 누적해서 표시
```

🔽 교안
```py
# 가위 바위 보 게임(3판 2선승제)

# 난수 생성 random import, 제일 먼저 필요한것들 import 해놓기
import random

# 번호와 hands sign 저장한 딕셔너리
HANDS = {1:"가위", 2:"바위", 3:"보"}
# 전체 대문자 변수 : 컨스턴트, 바뀌지 않는 변수, 상수 등 의미(관례)
# 📌 내 코드 : 리스트 -> 인덱스로 호출. 이렇게 보니 딕셔너리 자료형이 더 적합한 것 같다! 딕셔너리 쓸 생각을 못했다. 그냥 리스트가 떠올랐고 아무 고민없이 go 함.
# ⭐ 코드마다 각 데이터에 적합한 자료구조를 찾아서 잘 쓰는 것도 필요함 !
# 숫자와 의미를 원하는 대로 연결하는 것이 중요하면 딕셔너리

# 게임 타이틀 출력 함수
# 📌내 코드 : 함수로 써야하나 고민하다가 냅다 while문만 적음ㅠㅠ
# ⭐ 기능을 함수 단위로 묶는 연습하기 !
def show_title():
    print("="*40)
    print("가위/바위/보 게임")  # print(f"{'가위/바위/보 게임':<30}")?
    print("="*40)

# 플레이어 이름 입력함수
def ask_name():
    name = input("플레이어 이름을 입력하세요.: ").strip() # 공백 있다면 삭제
    if name == "": # 아무것도 입력 안하면
        name = "게스트" # 게스트로 기본 지정
    return name
    # 📌내 코드 : strip(), if name == "" 같은 디테일을 떠올리지 못했음.
    # 항상 확장적으로 사고하기. 사람은 컴퓨터가 아니다!

# 게임을 실행하면 돌릴 전체 루프 main 함수 작성
def main():
    show_title() # 게임 타이틀 출력 함수 호출
    name = ask_name() # 플레이어 이름 입력함수 호출

    computer_number = random.randint(1,3) # 컴퓨터의 sign 결정 
    # print(computer_number) 넣어서 아래에 숫자와 가위,바위,보가 매치되는지 확인
    print(f"{name}님, 컴퓨터는 {HANDS[computer_number]}를 냈습니다.")
    # 딕셔너리에서 키(1~3 숫자)로 가위, 바위, 보 이름 불러오기

# 게임 실행
main()
```
