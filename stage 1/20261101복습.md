
터미널 관련 복습

```sh
# 파일 move : mv + 무엇을 + 어디로
mv memo.md notes/

# 파일 copy : cp + 원본 + 복사본 으로 파일 복사
cp notes/memo.md plan.md

# 이름 바꾸기(별도 명령어 x) : mv + 원래 이름 + 새 이름
mv plan.md todo.md

# 파일 삭제 : rm, 휴지통 거치치 않고 삭제(복원 x)
pwd로 현재 위치 확인 > ls로 지울 이름 확인 > rm 지우기

# 폴더 삭제 : rm -r, 하위 파일까지 모두 삭제
rm -r notes

# 강제 전체 삭제 : rm -rf, -r 폴더 안까지 전부, -f 강제로 삭제(에러 무시)
rm -rf old


```
