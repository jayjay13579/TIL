## 터미널 명령어(2)

- rm : 파일 삭제(remove) -> 보통은 관습적으로 -rf까지 붙여서 씀
$ rm README.md

- rm -rf : r recursive 하위 폴더 모두 삭제, f force 확인없이 강제 삭제, 폴더 전체 삭제 -> 복구 불가
$ rm -rf kant/

- rm -rf . -> 잘못하면 현재 디렉터리에 있는 것 모두 삭제 됨

- '# 등 마크다운 문법을 활용하여 내용 작성하기
$ echo "# Markdown Tutorial" > README.md

- '#에서 뒤에 한칸 띄워줘야 인식 / 마크다운에서 '# 하나 -> html의 h1과 동일

### 헤드 이동해서 이전 버전 확인하기(삭제x)

- 헤드 잠깐 옮겨서 (뒤로 되돌아가기) git reset, git revert 쓰지 않고하는 방법

> 몇 칸 뒤로 갈 지 횟수로 이동할 수도 있고, 해시값으로 이동할 수도 있음

```
$ git checkout 39703a7(이동할 커밋의 해시값)
```
해당 커밋 되기 전의 상태로 문서가 되돌아감, 단 checkout이라서 뒤의 것이 지워진 것이 아니고 잠깐 점프만 한 상태일 뿐

```
jihey@LAPTOP-T7TVDFIE UCRT64 C:/Users/jihey/kant ((39703a7...))
```
head가 main이 아니고 해당 해시값으로 나타나는 것 확인 가능

이런 작업, add, commit, checkout 등 작업 하기 전에 반드시 파일 저장상태 확인. 

- --oneline만하면 해당 헤드 있는 커밋만 보임
```
jihey@LAPTOP-T7TVDFIE UCRT64 C:/Users/jihey/kant ((39703a7...))
$ git log --oneline
39703a7 (HEAD) docs: 헤더 내용 추가
096bb9f feat: Add README.md
```

- --all 붙이면 전체 커밋 보임
