## `fillna()` : 결측치 채우기

- 판다스에서 결측치(`NaN`)를 다른 값으로 채우는 메서드
- **Series(컬럼 하나)**와 **DataFrame 전체**에 사용할 수 있음
- 기본적으로 채운 결과를 반환하며, 원본에 반영하려면 다시 저장해야 함

### 기본 문법

```python
대상.fillna(채울_값)
```

### 예시 데이터

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "age": [20, np.nan, 30],
    "score": [80, np.nan, 90]
})
```

| 인덱스 | age | score |
|---:|---:|---:|
| 0 | 20 | 80 |
| 1 | NaN | NaN |
| 2 | 30 | 90 |

### 1. 특정 컬럼의 결측치 채우기

```python
df["age"] = df["age"].fillna(25)
```

- `age` 컬럼의 결측치를 `25`로 채워 다시 저장
- 다른 컬럼은 바뀌지 않음

### 2. 특정 컬럼의 평균으로 채우기

```python
mean_age = df["age"].mean()            # age의 평균 계산
df["age"] = df["age"].fillna(mean_age) # 결측치를 평균으로 채워 저장
```

- `mean()`은 기본적으로 결측치를 제외하고 평균을 계산함
- 한 줄로도 작성할 수 있음

```python
df["age"] = df["age"].fillna(df["age"].mean())
```

### 3. DataFrame 전체의 결측치 채우기

```python
df = df.fillna(0)
```

- DataFrame 전체에서 결측치를 찾아 `0`으로 채움
- 모든 컬럼에 같은 값을 적용하므로 데이터의 의미와 자료형을 확인해야 함

### 4. 컬럼마다 다른 값으로 채우기

```python
df = df.fillna({
    "age": 25,
    "score": 85
})
```

- `age`의 결측치는 `25`로 채움
- `score`의 결측치는 `85`로 채움
- 딕셔너리에 지정하지 않은 컬럼은 그대로 둠

### 5. 특정 행의 결측치 채우기

```python
df.loc[1] = df.loc[1].fillna(0)
```

- 인덱스가 `1`인 행의 결측치만 `0`으로 채움
- `1`은 행의 위치가 아니라 **인덱스 이름**임

특정 행에서 컬럼마다 다른 값을 넣을 수도 있음:

```python
df.loc[1] = df.loc[1].fillna({
    "age": 25,
    "score": 85
})
```

### 주의: 결과를 다시 저장해야 원본에 반영됨

```python
# 채운 결과를 반환하지만 원본 df에는 자동으로 반영되지 않음
df["age"].fillna(25)

# 반환된 결과를 다시 저장
df["age"] = df["age"].fillna(25)
```

> 위 예시들은 각각 별도로 실행한다고 가정함.
> 앞에서 이미 결측치를 채웠다면 이후 코드에서는 채울 `NaN`이 없을 수 있음.

## 범주형 컬럼에 새 범주를 추가하고 결측치 채우기

`deck`이 범주형(`category`) 컬럼이라면, 기존 범주에 없는 값을 결측치에 넣기 전에 **범주 목록에 먼저 추가**해야 한다.

### 단계별로 작성하기

```python
# 1. "Unknown"을 deck의 범주 목록에 추가
df["deck"] = df["deck"].cat.add_categories("Unknown")

# 2. deck의 결측치를 "Unknown"으로 채우기
df["deck"] = df["deck"].fillna("Unknown")
```

### 한 줄로 작성하기

```python
df["deck"] = df["deck"].cat.add_categories("Unknown").fillna("Unknown")
```

- `.cat`: 범주형 데이터의 기능에 접근
- `.add_categories("Unknown")`: 범주 목록에 `"Unknown"` 추가
- `.fillna("Unknown")`: 결측치를 `"Unknown"`으로 채움
- `df["deck"] = ...`: 결과를 원래 컬럼에 저장

### `loc`를 쓰면 안 될까? ⭐⭐⭐⭐⭐(오류 원인)

```python
df.loc[:, "deck"] = (
    df["deck"].cat.add_categories("Unknown").fillna("Unknown")
)
```

- `loc`를 이용한 대입 자체는 올바른 문법이다.
- 다만 기존 컬럼이 범주형인 경우, 판다스 버전이나 상황에 따라 `loc`가 기존 범주형 자료를 유지하면서 대입하려고 해 오류가 발생할 수 있다.
- 새 범주가 포함된 **컬럼 전체를 교체**할 때는 `df["deck"] = ...` 방식을 사용할 수 있다.

### 범주 확인하기

```python
df["deck"].cat.categories
```

> `"Unknown"`이 이미 범주 목록에 있다면 다시 추가할 수 없다.
> 이때는 `add_categories()` 없이 `fillna("Unknown")`만 사용한다.
