1. ipykernel 개념 복습

- ipykernel은 Jupyter 노트북에 적은 파이썬 코드를 실제로 실행해 주는 역할

  - ipykernel: VS Code에서 보낸 코드를 받아 파이썬으로 실행하고, 결과를 돌려주는 실행 담당자
  - VS Code: 돌려받은 결과를 셀 아래에 보여줌

## 2️⃣ NumPy, Pandas 활용하기

> NumPy는 숫자 묶음을 한 번에 계산하고, pandas는 그 위에 이름표를 붙여 엑셀같은 표로 다룸

### 1. NumPy
- 보통 np라는 별칭으로 import하여 사용
```py
# numpy import
import numpy as np
```

#### (1) 배열 생성 np.array()
- np.array() : 여러 값이 담긴 데이터를 NumPy 배열로 생성
```py
amounts = [3200, 1500, 15000, 6500, 32000, 4800,
           10900, 1500, 2700, 3000, 18500, 7000]
arr = np.array(amounts)
print(type(arr)) # 리스트처럼 생겼지만 배열 <class 'numpy.ndarray'>
# [ 3200  1500 15000  6500 32000  4800 10900  1500  2700  3000 18500  7000]
```

#### (2) 배열 연산
- NumPy 배열을 계산식에 넣으면, 배열 각 값에 한번에 같은 계산 적용할 수 있음
```py 
print(arr * 2) # 배열 내 모든 값에 *2 한 결과를 반환
# [ 6400  3000 30000 13000 64000  9600 21800  3000  5400  6000 37000 14000]
```
- [비교] python 리스트 * 2 를 하면 해당 리스트를 두 번 이어 붙여 출력("="*2 원리 참고)
  - 리스트는 '값 묶음'이지 '숫자 묶음'이 아니라서 안의 숫자에 곱하는 기능이 없음!  
  => ⭐ 자료 내부 값들에 연산을 적용하기 위해서는 배열로 만들어야 한다! ⭐


#### (3) 계산 함수
- 배열.sum/mean/min/max() : 배열 내 값들에 대해 합계, 평균, 최솟값, 최댓값 계산
```py
print(arr.sum()) # 합계 : 106600
print(round(arr.mean())) # 평균 : 8883
print(arr.min()) # 최솟값 : 1500
print(arr.max()) # 최댓값 : 32000
```

#### (4) 배열 정보 확인
- 배열 정보 확인 : (모양) 배열.shape, (데이터 타입) 배열.dtype
```py
print("모양:", arr.shape, "데이터 타입: ", arr.dtype)
# 모양: (12,) 데이터 타입:  int64
# 값이 12개 들어있는 1차원 배열, 64비트 정수형의 값들
```

#### (5) 조건 검증, 값 추출
- 개별 값 조건 검증(T/F)
```py
print(arr >= 10000) # 칸 마다 만원 이상인지 확인 -> T/F 배열 반환
# [False False True False True False True False False False True False]
```

- 조건 해당 값만 추출 : 배열[조건] -> 대괄호 내에 조건을 작성, 해당하는 값만 반환
```py
arr[arr>=10000] # arr 배열 값 중 10000 이상인 것
# array([15000, 32000, 10900, 18500])
# 🚨 그냥 >=10000만 적으면 안되고 배열명>=10000으로 적어야 함!
```

### 2. Pandas

#### Pandas의 필요성 ❓

- numpy 배열에는 한 종류의 데이터만 담을 수 있음, 글자가 하나라도 섞이면 전부 글자로 바뀜
  - 숫자끼리 더할 수도 없고, 어느 칸이 어떤 열의 값인지 이름표도 없음
```py
mixed = np.array([["편의점", 3200],
                  ["버스",   1500]])
print(mixed)
print("값의 종류:", mixed.dtype) # <U21 (최대 21글자짜리 문자열)
```

➡️ Numpy 배열의 한계를 뛰어넘어 열마다 다른 데이터 타입의 값들을 담고  
    항목별로 이름을 붙이기 위해, 표 형태를 만들 수 있는 Pandas 도구 필요

#### (1) DataFrame 생성 : pd.DataFrame({컬럼명1 : 데이터, 컬럼명2: 데이터, ...})

- [Pandas가 없다면] 파이썬 내장 함수 zip으로 값들 연결하여 식비 합계 구하기
  - zip : 여러 자료에서 같은 위치에 있는 값끼리 묶어 튜플쌍으로 만듦,  
    zip 객체는 값을 한번 꺼내쓰면 소진되므로 다시 쓸땐 새로 만들어야
```py
amounts = [3200, 1500, 15000, 6500, 32000, 4800,
           10900, 1500, 2700, 3000, 18500, 7000]

shops = ["편의점", "버스", "영화관", "분식집", "온라인쇼핑", "카페",
         "음원앱", "버스", "편의점", "웹툰", "온라인쇼핑", "분식집"]

categories = ["식비", "교통", "문화", "식비", "쇼핑", "식비",
              "문화", "교통", "식비", "문화", "쇼핑", "식비"]

food = 0
for c, a in zip(categories, amounts): # for문을 사용하여 코드가 길어진다
    if c == "식비":
        food += a
print(food) # 24200
```

- loc[행 이름표, 열 이름표]를 활용, 원하는 데이터를 선택하고 변경할 수 있음
```py
# 인덱스 2번 행(0번부터 시작하므로 실질적으론 세 번째 행)의 amount 값 변경
spend.loc[2, "amount"] = 14000 # 기존 15000 -> 14000으로 변경

spend["point"] = spend["amount"] // 100 # 포인트 열의 값도 다시 갱신하기
# 앞에서 미리 계산해둔 값은, 연동된 값이 바뀌어도 자동으로 갱신되지 않음! (엑셀과의 차이)
```
